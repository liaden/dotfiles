# Global rules

- Comments explain WHY only, and are rare. If code needs a WHAT comment, refactor it.
- Tests first: show the failing run, then the passing run.
- Commit messages, summaries, and documents: no em dashes, digits for numbers, plain
  words.
- Shared rules live in `~/.claude/reference/`: `principles.md` (design and review),
  `coding.md` (comments, tests, commits), `writing-style.md` (read before writing a
  document). Read the one the task needs.
- To find past decisions, use mempalace, read-only. See `~/.claude/reference/mempalace.md`.
- The repo `CLAUDE.md` wins over this file.
